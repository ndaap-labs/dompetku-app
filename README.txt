# 💰 Dompetku – PWA Expense Tracker

**Dompetku** adalah aplikasi web *Progressive Web App* (PWA) modern yang dirancang untuk membantu pengguna memantau, mencatat, dan mengelola pengeluaran keuangan harian hingga tahunan dengan antarmuka yang bersih, responsif, dan elegan menggunakan estetika *glassmorphism*.

✨ Fitur Utama
- **Autentikasi Pengguna Nyata**: Sistem Masuk (*Login*) dan Daftar Akun (*Register*) berbasis `localStorage` dengan penyimpanan data yang terisolasi per akun.
- **Pencatatan Keuangan Interaktif**: Catat pengeluaran harian lengkap dengan kategori, nominal, tanggal, dan catatan khusus.
- **Format Mata Uang Otomatis**: Input nominal secara otomatis terformat dengan pemisah ribuan Rupiah (IDR).
- **Statistik & Visualisasi**: Grafik donat interaktif per kategori pengeluaran dan diagram tren waktu (harian, mingguan, bulanan, tahunan).
- **Mode Tampilan (Theme Switcher)**: Mendukung mode Terang (*Light*) dan Gelap (*Dark*) yang selaras secara otomatis.
- **PWA Ready**: Dapat diinstal langsung ke perangkat mobile atau desktop seperti aplikasi native.

🛠️ Teknologi yang Digunakan
- **HTML5 & CSS3** (Custom Modern Variables, Glassmorphism UI)
- **JavaScript (ES6+ Vanilla)** tanpa ketergantungan *framework* berat
- **LocalStorage API** untuk manajemen basis data lokal dan sesi pengguna
- **Service Workers** untuk dukungan PWA
